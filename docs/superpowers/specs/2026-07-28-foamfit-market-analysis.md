## 1. 경쟁사 CWS의 시장 구조 이해

### CWS Hygiene이란

CWS(Clean, Wash, Service)는 독일 기반의 B2B 화장실 위생 서비스 기업이다.
디스펜서 설치 + 리필 공급 + 유지관리를 묶어 렌탈 구독 형태로 제공한다.
소비자에게 직접 판매하는 제품이 아니라 **기업·기관·시설 운영자가 고객**이다.

### CWS의 진출 국가

현재 유럽 **15개국**에서 직접 서비스 운영 중이다.

| 권역 | 국가 |
|------|------|
| 독일어권 | 독일, 오스트리아, 스위스 |
| 베네룩스 | 벨기에, 네덜란드, 룩셈부르크 |
| 북유럽 | 스웨덴, 아일랜드 |
| 중·동유럽 | 폴란드, 체코, 크로아티아, 슬로베니아, 헝가리, 슬로바키아, 루마니아 |

> 독일이 핵심 시장. 2019 Haniel 연간보고서에서도 CWS Hygiene 성장에 독일 사업이 가장 크게 기여했다고 명시.
> 한국 진출 없음 → FoamFit의 국내 선점 기회.

### CWS의 B2B 타겟 산업

CWS는 다음 산업군 시설에 화장실 위생 서비스를 제공한다.

- 오피스 빌딩
- 제조업·산업시설
- 병원 및 의료시설
- 호텔·레스토랑 (Hospitality)
- 학교·교육시설
- 어린이집
- 레저·스포츠시설
- 쇼핑몰·유통시설

> FoamFit도 동일한 고객군을 타겟으로 삼을 수 있다. CWS의 유럽 성공은 이 B2B 모델이 검증됐음을 보여준다.

## 2. FoamFit의 우선 타겟 고객 (한국 기준)

CWS의 타겟 산업을 한국 맥락에 맞게 우선순위화한다.

| 우선순위 | 고객 유형 | 이유 |
|----------|-----------|------|
| 1 | 병원·건강검진센터 | 민감한 피부, 환자 위생, 비데 설치 제한적 |
| 2 | 고급 오피스 빌딩 | 직원 복지·화장실 서비스 차별화 니즈 |
| 3 | 호텔·리조트 | 고객 경험·위생 수준 향상 경쟁 |
| 4 | 고속도로 휴게소 | 높은 이용량, 비데 없는 칸 다수 |
| 5 | 백화점·쇼핑몰 | 고객 서비스 차별화 포인트 |
| 6 | 어린이집·키즈카페 | 어린이·민감성 피부 이용자 |
| 7 | 요양원 | 고령자 위생 지원, 반복 사용 빈도 높음 |
| 8 | 골프장·스포츠센터 | 샤워·화장실 서비스 개선 경쟁 |

> **CWS도 어린이·아기·민감성 피부 이용자에게 적합한 제품으로 Toilet Paper Foam을 포지셔닝한다.** FoamFit의 세정+보습+영양 포뮬러는 이 포지셔닝과 직접 연결된다.

## 3. 지역별 진출 순서

### 1단계: 수도권 민간 프리미엄 시설

> **서울 → 경기 남부 → 인천**

| 이유 | 설명 |
|------|------|
| 대기업 본사·대형 오피스 밀집 | 의사결정 빠르고 예산 있음 |
| 병원·백화점·호텔 집중 | 위생 기대치 높음 |
| 시설관리 전문회사 다수 | 파트너십 채널 활용 가능 |
| 관리·배송 용이 | 초기 운영 비용 최소화 |
| 현장 테스트 접근 쉬움 | 빠른 피드백 사이클 |

> 지자체 공공입찰보다 **민간 B2B 고객(병원·백화점·골프장)부터 접근하는 것이 현실적이다.** 허가 속도와 계약 유연성이 다르다.

### 2단계: 전국 다점포 고객 (본사 계약)

성공사례 확보 후, 화장실 1곳씩 파는 것이 아니라 **본사 계약 → 전국 동시 설치** 구조로 전환한다.

주요 타겟:
- 대형 병원 체인 (상급종합병원 그룹)
- 백화점·쇼핑몰 체인 (롯데, 신세계, 현대 등)
- 고속도로 휴게소 운영사 (한국도로공사 등)
- 호텔 체인 (국내 브랜드 + 외국계 호텔)
- 프랜차이즈 카페 본사
- 골프장 운영사
- 대기업 오피스 총무팀
- 시설관리 전문회사 (ISS, 에스코 등)

### 3단계: 해외 진출

CWS가 강한 유럽 시장과 정면 경쟁보다 **틈새 시장**을 노린다.

| 지역 | 이유 |
|------|------|
| 일본 | 위생 의식 높음, 비데 없는 공중화장실 다수 |
| 싱가포르·홍콩 | 프리미엄 B2B 시장, 영어 사용 |
| 대만 | 한국과 유사한 시장 구조 |
| 중동 (호텔·쇼핑몰) | 고급 시설 집중, 위생 수요 높음 |
| 북미·유럽 일부 | 비데 보급률 낮은 지역 틈새 |

> 해외에서는 특허·디자인·원가·리필 호환성으로 차별화가 필요하다. CWS와 직접 비교 테스트가 가능한 수준의 포뮬러 품질 확보가 전제.

## 4. 매출 계산 기본 가정

> ⚠️ 아래 수치는 **사업 가능성 검토용 가정값**이다. 실제 가격은 파일럿 결과를 바탕으로 확정해야 한다.

| 항목 | 가정값 | 비고 |
|------|--------|------|
| 디스펜서 설치비 | 100,000원 / 대 | 초기 진입가 (추후 조정 가능) |
| 월 렌탈·관리비 | 10,000원 / 대 | 유지관리 포함 |
| 월 리필(소모품) 매출 | 20,000원 / 대 | 폼 카트리지 교체 기준 |
| **월 반복 매출 합계** | **30,000원 / 대** | 렌탈 + 리필 |
| **연간 반복 매출** | **360,000원 / 대** | 월 3만 원 × 12 |

**핵심 공식:**
```
연간 매출 = 설치 대수 × 월평균 반복 매출(3만 원) × 12개월
```

## 5. 매출 시나리오

### 시나리오 A: 초기 시장 진입

> 50개 시설 × 10대 = 500대

| 구분 | 매출 |
|------|------|
| 디스펜서 설치 (500대 × 10만 원) | 5,000만 원 |
| 연간 렌탈·리필 (500대 × 36만 원) | 1억 8,000만 원 |
| **첫해 합계** | **약 2억 3,000만 원** |

### 시나리오 B: Product-Market Fit 확인

> 200개 시설 × 10대 = 2,000대

| 구분 | 매출 |
|------|------|
| 디스펜서 설치 (2,000대 × 10만 원) | 2억 원 |
| 연간 렌탈·리필 (2,000대 × 36만 원) | 7억 2,000만 원 |
| **첫해 합계** | **약 9억 2,000만 원** |

> 2년 차부터 신규 설치 없이 반복 매출만 **7억 2,000만 원** 발생.

### 시나리오 C: 한국 시장 확장

> 1,000개 시설 × 10대 = 10,000대

| 구분 | 매출 |
|------|------|
| 디스펜서 설치 (10,000대 × 10만 원) | 10억 원 |
| 연간 렌탈·리필 (10,000대 × 36만 원) | 36억 원 |
| **연간 합계** | **46억 원** |

### 시나리오 D: 전국 대형 B2B

> 5,000개 시설 × 10대 = 50,000대

| 구분 | 매출 |
|------|------|
| 디스펜서 설치 (50,000대 × 10만 원) | 50억 원 |
| 연간 렌탈·리필 (50,000대 × 36만 원) | 180억 원 |
| **연간 합계** | **230억 원** |
| 이후 연간 반복 매출 | **180억 원** |

## 6. TAM · SAM · SOM

### TAM — 한국 전체 잠재시장

| 가정 항목 | 값 |
|----------|-----|
| 설치 가능 공공·상업 시설 수 | 50,000개 (추정) |
| 시설당 평균 설치 대수 | 10대 |
| 총 잠재 설치 디스펜서 | 500,000대 |
| 대당 연간 반복 매출 | 360,000원 |
| **TAM** | **연간 약 1,800억 원** |

> ⚠️ 50,000개 시설은 공식 통계 기반이 아닌 모델 가정값. 실제 검증 필요.

### SAM — 수도권 프리미엄 B2B 시장

> 수도권 병원·백화점·쇼핑몰·호텔·대기업 오피스 5,000개 시설 기준

```
5,000개 시설 × 10대 × 360,000원 = 연간 약 180억 원
```

### SOM — 3~5년 내 확보 가능 시장

| 시장점유율 | 시설 수 | 설치 대수 | 연간 반복 매출 |
|----------|---------|-----------|--------------|
| 1% | 50개 | 500대 | 1.8억 원 |
| 3% | 150개 | 1,500대 | 5.4억 원 |
| **5%** | **250개** | **2,500대** | **9억 원** |
| 10% | 500개 | 5,000대 | 18억 원 |

**현실적 3년 SOM 목표:**
> 250개 시설, 2,500대 설치, 연간 반복 매출 **9억 원**
> 설치비 포함 시 해당 연도 전체 매출 약 **11억~12억 원**

## 9. 시장 추정에서 가장 중요한 검증 항목 3가지

이 모든 숫자는 아래 세 가지가 확인돼야 의미가 있다.

| 검증 항목 | 왜 중요한가 | 검증 방법 |
|-----------|------------|-----------|
| **① 시설당 실제 설치 가능 디스펜서 수** | 10대는 가정값. 3대일 수도, 30대일 수도 있다 | 병원·백화점·오피스 10곳씩 직접 조사 |
| **② 대당 월평균 폼 사용량** | 소모량이 리필 주기와 단가를 결정한다 | 파일럿 설치 후 실측 |
| **③ 고객이 수용 가능한 월 렌탈·관리 가격** | 3만 원이 너무 높을 수도, 너무 낮을 수도 있다 | 운영자 가격 테스트 (Phase 6) |

## 10. 다음 단계: Bottom-up 시장 검증

전국 전체 화장실 수를 추정하는 Top-down 방식보다, 작은 샘플에서 실제 데이터를 얻는 **Bottom-up 방식**이 지금 단계에서 더 정확하다.

### 즉시 실행할 Bottom-up 조사

| 조사 대상 | 목표 샘플 | 확인할 것 |
|-----------|-----------|-----------|
| 병원 | 10곳 | 화장실 칸 수, 담당자, 지불 의향 |
| 백화점·쇼핑몰 | 10곳 | 화장실 칸 수, 청결 정책, 예산 |
| 대기업 오피스 | 10곳 | 층당 화장실 수, 총무 담당 접촉 |

이 30개 시설 데이터가 나오면 SAM 추정의 정확도가 크게 높아진다.

> CWS 사례는 **시장이 존재한다는 근거**다. FoamFit의 실제 매출은 **한국 고객의 사용량과 계약 가격**으로 결정된다.
