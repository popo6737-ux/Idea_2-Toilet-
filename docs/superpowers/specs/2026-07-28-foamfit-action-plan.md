# FoamFit 사업화 실행 계획

**Customer → Problem → Hypothesis → Experiment → Learning → MVP → Paid Pilot → Business Model → Launch**

> 버전: 1.0 | 작성일: 2026-07-28

---

## 핵심 원칙

> **제품을 먼저 완성하지 않는다.**
> 가장 위험한 가정을 가장 작은 비용으로 하나씩 검증한다.

이 계획은 **Customer Identification, Value Proposition Canvas, Lean Hypothesis Testing, Build–Measure–Learn, Affordable Loss**를 FoamFit에 적용한 6개월 실행안이다.

## 전체 일정 요약

| 단계 | 기간 | 핵심 질문 | 통과 기준 |
|------|------|-----------|-----------|
| 1. 고객·문제 정의 | 1~2주 | 누구의 어떤 문제를 해결하는가? | 사용자·지불자·승인자 구분 완료 |
| 2. 고객 인터뷰 | 3~4주 | 문제가 실제로 중요한가? | 반복되는 Pain Point 확인 |
| 3. 가설·실험 설계 | 5주 | 무엇을 먼저 검증해야 하는가? | 측정 가능한 가설 3개 확정 |
| 4. 저비용 MVP 제작 | 6~8주 | 최소 기능으로 사용 행동을 볼 수 있는가? | 실제 설치 가능한 프로토타입 완성 |
| 5. 화장실 사용 테스트 | 9~10주 | 사람들이 실제로 사용하는가? | 사용률·만족도·관리성 측정 |

| 7. 제품·운영 개선 | 4개월 차 | 반복 사용과 관리가 가능한가? | 사용 오류·관리시간 감소 |
| 8. 유료 파일럿 | 5개월 차 | 실제 계약 가능성이 있는가? | 실제 결제 + 반복 사용 확인 |
| 9. 사업모델 확정 | 6개월 차 | 수익성 있게 확장 가능한가? | Continue / Pivot / Stop 결정 |

## Phase 1. 고객과 문제 정의 `1~2주`

### 왜 고객 구조부터 정해야 하는가

공용화장실 사업에서 고객은 하나가 아니다. 사용하는 사람과 돈을 내는 사람이 다르다.

```
User (사용자)          → 공용화장실 이용객
Payer (지불자)         → 시설 운영자 (카페, 호텔, 사무실 등)
Buyer / Approver (결정자) → 시설관리 담당, 총무, 건물주, 프랜차이즈 본사
```

이 세 역할이 같은 사람일 수도 있고 다른 사람일 수도 있다.
**설득 대상이 누구인지 먼저 확정해야 인터뷰와 영업이 흔들리지 않는다.**

### 초기 타겟 세그먼트 선택 기준

첫 실험 장소는 다음 5가지 조건을 모두 충족하는 곳으로 한다.

| 조건 | 이유 |
|------|------|
| 비데가 없는 화장실 | FoamFit의 명확한 필요성 존재 |
| 이용객이 어느 정도 있음 | 의미 있는 사용 데이터 수집 가능 |
| 청결·고객 만족이 중요 | 지불 동기 존재 |
| 관리자에게 직접 접근 가능 | 빠른 허가·피드백 |
| 테스트 허가받기 쉬움 | 규모가 작고 의사결정이 빠른 곳 |

**추천 첫 세그먼트:** 중형 카페, 실내 골프연습장, 공유오피스, 소형 호텔·게스트하우스

> 대형 쇼핑몰이나 공공기관은 허가 절차가 길고 의사결정이 느려 초기 실험에 적합하지 않다.

### Phase 1 결과물

다음 한 문장을 완성한다.

> **"FoamFit은 [타겟 장소 유형]의 [구체적 사용자]에게 [비데 없이도 깨끗하게 닦을 수 있는 경험]을 제공한다. 비용은 [지불자]가 부담한다."**

## Phase 2. 고객 문제 인터뷰 `3~4주`

### 원칙: 팔려고 하지 말고 배우러 간다

이 단계에서 FoamFit을 소개하면 안 된다.
고객이 지금 어떻게 살고 있는지, 실제로 어떤 행동을 하는지 관찰하는 단계다.

### 인터뷰 목표

| 대상 | 목표 인원 |
|------|-----------|
| 공용화장실 이용자 | 20~30명 |
| 시설 운영자 (카페·오피스·호텔 관리자 등) | 10명 |

### 이용자 인터뷰 질문

**과거 행동을 묻는 질문 (신뢰도 높음)**

1. 비데가 없는 공용화장실을 최근 한 달에 얼마나 자주 이용하셨나요?
2. 그 중 대변 후 청결감이 부족하다고 느낀 적이 있었나요? 어떻게 하셨나요?
3. 물티슈나 개인 위생용품을 따로 챙겨 다니시나요? 언제부터 그러셨나요?
4. 공용화장실 위생 때문에 이용을 참거나 피한 경험이 있나요?
5. 지금 방식에서 가장 불편한 점은 무엇인가요?

**피해야 할 질문 (신뢰도 낮음)**

> ~~"FoamFit이 있으면 사용하시겠어요?"~~ → 사람들은 친절하게 "네"라고 답하는 경향이 있다.

### 운영자 인터뷰 질문

1. 화장실과 관련해 고객 불만이나 민원을 받은 적 있나요?
2. 현재 화장실 위생 관련해 어떤 제품이나 방법을 쓰고 계신가요?
3. 직원이 화장실 관리에 하루 얼마나 시간을 쓰나요?
4. 새 화장실 제품 도입 시 가장 걱정하는 것이 무엇인가요?
5. 구매·설치 비용 승인은 누가 하나요? 예산 한도는요?
6. 소모품 보충에 주 몇 회, 몇 분 이상 걸리면 부담스러운가요?

### Go / No-Go 기준

다음 중 **3개 이상** 확인되면 Phase 3으로 진행한다.

- [ ] 이용자 20명 중 10명 이상이 반복적 불편을 경험함
- [ ] 일부 이용자가 이미 개인 물티슈 등 대체재를 직접 챙김
- [ ] 운영자 3명 이상이 위생·고객만족 문제를 실제 문제로 인정함
- [ ] 현재도 해결을 위해 비용이나 관리 시간을 쓰고 있음
- [ ] 변비 환자 또는 민감한 피부 이용자 중 강한 니즈 확인

**No-Go 신호:** 대부분이 "전혀 불편하지 않다"고 답하면 고객 세그먼트나 문제 정의를 재검토한다.

## Phase 3. 핵심 가설 결정 `5주`

인터뷰 결과를 바탕으로 **가장 위험한 가설 3개**를 선택한다.
위험한 가설 = 틀렸을 때 사업 전체가 흔들리는 가정

### 가설 카드

#### 가설 1 — 고객 니즈 (Desirability)

> 비데가 없는 공용화장실 이용자는 더 위생적이고 편안한 경험을 원하며, FoamFit을 실제로 사용할 것이다.

| 항목 | 내용 |
|------|------|
| 검증 방법 | 실제 화장실 설치 후 사용률 측정 |
| 성공 기준 | 예상 이용자 중 20% 이상 자발 사용 |
| 실패 시 조치 | 세그먼트 변경 또는 제품 컨셉 재검토 |

#### 가설 2 — 사용·관리 가능성 (Feasibility)

> 이용자는 별도 설명 없이 FoamFit을 올바르게 사용할 수 있고, 운영자는 하루 10분 이내로 관리할 수 있다.

| 항목 | 내용 |
|------|------|
| 검증 방법 | 설명 없이 설치 후 오사용률 측정, 운영자 관리시간 기록 |
| 성공 기준 | 오사용 20% 미만 / 관리시간 10분 이내 |
| 실패 시 조치 | 안내 디자인 개선 또는 제품 구조 변경 |

#### 가설 3 — 지불 의사 (Viability)

> 시설 운영자는 화장실 위생 개선과 고객 만족을 위해 FoamFit 비용을 지불할 것이다.

| 항목 | 내용 |
|------|------|
| 검증 방법 | 구체적 가격 제시 후 유료 파일럿 의향 확인 |
| 성공 기준 | 접촉 운영자 중 30% 이상 유료 파일럿 의향 |
| 실패 시 조치 | 가격 구조 변경 또는 수익모델 피벗 |

## Phase 4. 저비용 MVP 제작 `6~8주`

### 핵심 원칙

> "얼마를 벌 수 있는가?"가 아니라 "얼마까지 잃어도 괜찮은가?" (Affordable Loss)

초기 실험 예산 상한선을 먼저 정한다. 예: **50만~150만 원 이내**

### MVP 최소 요건

FoamFit MVP가 갖춰야 할 것:

| 요건 | 이유 |
|------|------|
| 사용자가 사용법을 이해할 수 있는 표시 | 오사용률 최소화 |
| 1회 분사량 조절 기능 | 소모량·비용 계산을 위한 데이터 수집 |
| 안전하게 보관되는 구조 | 도난·오염 방지 |
| 사용 횟수 확인 방법 | 사용률 측정 (카운터 또는 무게 비교) |
| 간단한 보충·청소 구조 | 관리시간 측정 |

### 아직 필요 없는 것

| 항목 | 건너뛰는 이유 |
|------|---------------|
| 완성된 외관 디자인 | 검증 전 불필요한 비용 |
| 대량생산 금형 | 수요 확인 전 리스크 |
| 앱 연동·센서 | 핵심 가설과 무관 |
| 자체 폼 포뮬러 | OEM으로 우선 검증 가능 |
| 전국 유통·브랜드 패키지 | Phase 3 이후 과제 |

### MVP 버전별 목표

```
V1 (6주)  : 3D 프린팅 또는 기존 디스펜서 개조 → 기계식 펌프 작동 확인
V2 (7주)  : 사용 안내 부착 → 오사용률 측정
V3 (8주)  : 사용량 카운터 추가 → 소모량·사용빈도 데이터 수집
```

## Phase 5. 공용화장실 사용 테스트 `9~10주`

### 실험 설계

| 항목 | 내용 |
|------|------|
| 장소 | 비데 없고 이용자 수 파악 가능한 화장실 1곳 |
| 기간 | 최소 7일 (이상적으로 14일) |
| 폼 종류 | OEM 기성품 (자체 포뮬러는 Phase 7 이후) |

### 측정 항목

| 측정 항목 | 기록 방법 |
|-----------|-----------|
| 일일 이용자 수 | 입구 카운터 또는 운영자 추정치 |
| FoamFit 사용 횟수 | 폼 소모량(무게) 또는 카운터 |
| 사용률 | 사용 횟수 ÷ 이용자 수 |
| 하루 평균 사용량 (ml) | 전후 무게 측정 |
| 설명 없이 올바르게 사용한 비율 | 설치 후 첫 2일 관찰 |
| 잘못 사용한 사례 | 관찰 또는 흔적 확인 |
| 관리자 일일 관리시간 | 운영자 기록 |
| 사용 후 제품 주변 오염 여부 | 매일 사진 기록 |

### 사용자 설문 (QR 코드 부착)

```
1. FoamFit을 사용하셨나요?  ⬜ 예  ⬜ 아니오
2. 사용하셨다면 만족도는? (1~5점)
3. 다음에도 쓰고 싶으신가요?  ⬜ 예  ⬜ 아니오
4. 개선할 점이 있다면? (자유 응답)
```

### 성공 기준 (실험 전에 팀이 합의)

| 지표 | 목표치 | 근거 |
|------|--------|------|
| 자발 사용률 | 이용자의 20% 이상 | 기본 수요 존재 증명 |
| 사용자 만족도 | 평균 4점 이상 / 5점 | 재사용 의향 판단 |
| 재사용 의향 | 70% 이상 | 지속 가능성 판단 |
| 설명 없이 사용 성공률 | 80% 이상 | UX 직관성 판단 |
| 관리자 일일 관리시간 | 10분 이내 | 운영 부담 판단 |
| 심각한 위생·안전 문제 | 0건 | 기본 안전 기준 |

> ⚠️ 이 수치는 초기 가정이다. 인터뷰 데이터를 바탕으로 팀이 현실적으로 조정해야 한다.

### 사용률이 낮을 때 원인 구분

사용률 저조 = 즉각 실패가 아니다. **왜 사용하지 않았는지**를 파악하는 것이 더 중요하다.

| 원인 | 대응 |
|------|------|
| 제품을 발견하지 못함 | 위치·안내 개선 |
| 사용법을 이해하지 못함 | UX 개선 |
| 위생적으로 불안함 | 소재·디자인 신뢰도 향상 |
| 사용 결과가 만족스럽지 않음 | 폼 성분·분사량 조정 |
| 필요 자체를 못 느낌 | 세그먼트 재검토 |

## Phase 6. 지불 의사 검증 `11~12주`

### 수익모델 후보

| 모델 | 구조 | 장점 | 단점 |
|------|------|------|------|
| A. 기기 판매 | 디스펜서 구매 + 소모품 별도 | 초기 매출 발생 | 재구매 확보 어려움 |
| B. 렌털·구독 | 월정액에 기기+소모품+유지관리 포함 | 반복 수익, CWS 모델 검증됨 | 초기 현금흐름 느림 |
| C. 소모품 중심 | 기기 저가 공급 + 리필 판매 | 진입 장벽 낮음, 장기 마진 | 기기 손실 리스크 |
| D. 광고·스폰서 | 무료 설치 + 브랜드 광고 수익 | 운영자 허가 쉬움 | 광고주 확보 필요 |

> 초기에는 A, B, C 중 어떤 모델이 운영자에게 가장 받아들여지는지 비교 테스트한다.

### 가격 검증 방법

운영자에게 막연히 "얼마면 되겠어요?"를 묻지 않는다. **구체적 선택지를 제시하고 행동을 본다.**

제시 예시:
```
옵션 1: 기기 10만 원 구매 + 월 소모품 3만 원
옵션 2: 기기 무료 + 월 구독료 5만 원 (소모품 포함)
옵션 3: 1개월 유료 파일럿 5만 원 (기기+소모품 포함)
```

질문:
> **"이 조건이라면 실제로 1개월 시범 운영을 해 보시겠습니까?"**

### 증거 강도 순서

```
약한 증거                              강한 증거
────────────────────────────────────────────────────
"좋은 아이디어네요" → 관심 있다고 응답 → 후속 미팅 약속 → 유료 파일럿 신청 → 의향서 → 실제 결제
```

> **후속 미팅 약속 이상의 행동**이 나오지 않으면 지불 의사가 충분하지 않다고 본다.

## Phase 7. 제품·운영 개선 `4개월 차`

Phase 5~6 데이터를 기반으로 MVP를 개선한다.

### 개선 체크리스트

**사용자 측면**

- [ ] 사용법이 직관적인가? (오사용률 20% 이상이면 UX 재설계)
- [ ] 1회 분사량이 적절한가? (너무 많으면 낭비, 너무 적으면 불만족)
- [ ] 사용 후 효과가 분명하게 느껴지는가?
- [ ] 폼 성분이 피부 자극 없이 안전한가?

**운영자 측면**

- [ ] 보충이 5분 이내로 가능한가?
- [ ] 누수·오염 문제가 없는가?
- [ ] 도난·파손 위험을 줄일 수 있는가?
- [ ] 소모품 비용이 예측 가능한가?

**사업 측면**

단위 경제성을 처음으로 계산한다.

```
장소당 월 매출
  – 소모품 원가
  – 카트리지 배송비
  – 관리 방문비 (있는 경우)
  – 설치·초기 비용 분할
─────────────────
= 장소당 월 기여이익 (Contribution Margin)
```

> **기여이익이 마이너스**라면 원가 구조 또는 가격을 수정해야 한다. 운영 방문 없이 셀프관리가 가능한 구조가 핵심이다.

## 각 단계의 의사결정 기준

모든 단계 끝에 다음 세 가지 중 하나를 결정한다.

### Continue
가설이 충분히 지지되면 다음 단계로 진행

### Modify
문제는 있지만 사용법·가격·고객군이 잘못된 경우 수정 후 재실험

예:
- 사용률 저조 → 위치 변경 후 재실험
- 가격 거부 → 모델 A에서 B로 변경 후 재제안
- 특정 세그먼트만 강한 반응 → 해당 세그먼트에 집중

### Pivot
현재 고객·수익모델이 맞지 않으면 방향 변경

예:
- 일반 카페 → 골프장·프리미엄 시설로 세그먼트 변경
- B2B 판매 → B2B 구독으로 모델 변경
- 기기 중심 → 자체 폼 카트리지 구독 중심으로 전환

### Stop
고객 문제, 사용 행동, 지불 의사가 모두 약하면 추가 투자 중단

> 중단은 실패가 아니다. 큰 손실을 피하게 해 준 학습 결과다.
