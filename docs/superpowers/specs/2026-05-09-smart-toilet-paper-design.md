# 스마트 화장지 솔루션 기획서 (진행 중)

> 상태: 브레인스토밍 진행 중 | 최종 업데이트: 2026-05-09

---

## 1. 아이디어 개요

**제품명 (가칭):** 물티슈 없는 스마트 화장실 — 폼 분사 모듈

**한 줄 정의:**
공중화장실 점보롤 디스펜서에 부착하는 모듈형 장치로, 화장지를 뽑는 동작과 연동하여 거품(폼) 세정제를 자동 분사함으로써 물티슈 없이도 쾌적한 위생 경험을 제공한다.

---

## 2. 문제 정의 (Pain Point)

공중화장실에서 대변 후 일반 화장지만으로는 청결감이 부족하지만:
- 물티슈는 변기 막힘 유발 (배관 문제)
- 물티슈 쓰레기가 화장실 쓰레기통에 넘침
- 비데는 설치 비용·공간 문제로 공중화장실 보급 어려움

→ "깨끗하게 닦고 싶지만 물티슈는 쓰기 꺼려지는" 마찰(Friction) 지점

---

## 3. 시장 검증 (블라인드 앱 설문, n=18)

| 응답 | 비율 | 인원 |
|------|------|------|
| 물티슈가 모든 화장실에 있다면 쓴다 (= 잠재 고객) | **50.0%** | 9명 |
| 마른 휴지로도 충분하다 | 33.3% | 6명 |
| 물티슈도 귀찮아서 안 쓴다 | 16.7% | 3명 |

**핵심 인사이트:** 응답자 절반이 더 쾌적한 대안이 있다면 기꺼이 사용할 의향 있음.

---

## 4. 솔루션 방향

### 4-1. 분사 물질: 거품(폼) 세정제

- 순수 물(미스트) 대비 화장지에 덜 스며듦 → 찢어짐 방지
- 세정력 향상
- 유효기간이 길어 카트리지 교체 주기 확보 가능
- 참조: 시중 '뿌리는 비데' 폼 스프레이 제품군 (개인용 → 자동화)

### 4-2. 제품 형태: 모듈형 (부착형)

| 구분 | 일체형 | **모듈형 (채택)** |
|------|--------|-----------------|
| 설치 | 기존 디스펜서 전체 교체 | 기존 디스펜서에 부착 |
| 도입 장벽 | 높음 (전체 교체 결재) | 낮음 (PoC 테스트 용이) |
| 수익 모델 | 하드웨어 + 카트리지 | 모듈 + 카트리지 구독 |

**채택 이유:** B2B 고객(건물주·관리자)의 도입 장벽 최소화. 기존 점보롤 디스펜서를 그대로 두고 옆에 부착하는 방식으로 PoC(개념검증) 진입 용이.

### 4-3. 트리거 방식: 레버 연동형 (결정 중)

| 방식 | 특징 |
|------|------|
| A. 버튼형 | 단순하나 접촉 위생 문제 |
| B. 센서형 | 비접촉이나 분사 타이밍 제어 어려움 |
| **C. 레버 연동형 (추천)** | 화장지 뽑는 동작 자체가 트리거 → 별도 조작 불필요, 위생적 |

---

## 5. B2B 타겟 고객

- 고속도로 휴게소
- 공공기관 (정부·지자체 청사)
- 대형 쇼핑몰·복합시설
- 기업 오피스 빌딩

### B2B 설득 포인트

| 예상 반론 | 방어 논리 |
|-----------|-----------|
| "휴지 사용량 늘어나서 비용 증가 아닌가?" | 물티슈로 인한 변기 막힘 해결 비용 절감이 더 큼 |
| "설비 교체 비용이 부담스럽다" | 모듈형 부착 방식으로 기존 설비 그대로 사용 |
| "관리가 번거롭지 않나?" | 폼 카트리지 정기 구독으로 관리 일원화 |
