# FoamFit 기획서

**물티슈가 필요 없는 스마트 화장지 솔루션**

> 버전: 1.2 변비 유병률 시장 데이터 추가 | 작성일: 2026-07-28

---

## 1. 아이디어 개요

**제품명 (가칭):** FoamFit — 폼 분사 모듈

**한 줄 정의:**
공중화장실 점보롤 디스펜서에 부착하는 모듈형 장치로, 화장지를 뽑는 물리적 힘만으로 기계식 펌프를 작동시켜 **세정 + 보습 + 영양 기능성 폼**을 자동 분사함으로써 전기 없이도 물티슈 수준의 위생 경험을 제공한다.

**핵심 차별점:**
> 하드웨어가 아닌 **폼 포뮬러**가 우리의 핵심 자산이다.
> 세정력(Cleansing) + 보습(Moisturizing) + 영양(Nourishing) 3중 기능 조합으로 경쟁사가 모방할 수 없는 사용 경험을 만든다.

---

## 2. 문제 정의 (Pain Point)

공중화장실에서 대변 후 일반 화장지만으로는 청결감이 부족하지만:

- **변기 막힘:** 물티슈는 물에 녹지 않아 배관을 막고 수십만 원의 처리 비용을 유발
- **쓰레기 문제:** 물티슈 쓰레기가 화장실 쓰레기통을 가득 채워 관리 부담 증가
- **비데 보급 불가:** 설치 비용·공간·배관 문제로 공중화장실 보급 어려움

→ **"깨끗하게 닦고 싶지만 물티슈는 쓰기 꺼려지는"** 마찰(Friction) 지점

## 3. 시장 검증

### 3-1. 한국 성인 변비 유병률 (시장 규모 근거)

변비 환자는 배변 횟수가 많고 닦는 빈도가 높아 FoamFit의 **1순위 헤비유저**다.

| 측정 기준 | 유병률 | 비고 |
|-----------|--------|------|
| 본인이 변비라고 느끼는 사람 (자가 보고) | **16.5%** | 가장 넓은 잠재시장 정의 |
| 의학적 기준 기능성 변비 (Rome criteria) | **9.2%** | 보수적 시장 추정에 적합 |
| 엄격한 진단 기준 적용 시 | ~2.6% | 중증 변비 환자군 |

> **출처:** 한국 지역사회 기반 연구 (ResearchGate, PMC 등 복수 연구 종합)

**인구 환산 (한국 성인 약 4,300만 명 기준):**

| 시나리오 | 유병률 | 추정 인원 |
|----------|--------|-----------|
| 보수적 시장 | 9.2% | 약 **396만 명** |
| 현실적 잠재고객 | 15~17% | 약 **645~731만 명** |

**추가 인사이트:**
- 변비는 **여성과 고령층**에서 더 높게 나타남 → 공중화장실 위생 니즈가 특히 강한 집단
- 변비 환자일수록 닦는 횟수가 많아 물티슈 대안 수요가 일반인 대비 높음
- FoamFit의 보습·영양 성분은 변비로 인한 반복 닦기로 발생하는 **항문 주위 피부 자극 완화**에도 소구 가능

> ⚠️ **발표용 공식 수치:** "한국 성인의 약 10~17%가 변비를 경험한다 (정의에 따라 상이). 보수적으로 9.2%, 자가 보고 기준으로 16.5%."

### 3-2. 블라인드 앱 설문 (n=18, 2026)

| 응답 | 비율 | 인원 |
|------|------|------|
| 물티슈가 모든 화장실에 있다면 쓴다 **(= 잠재 고객)** | **50.0%** | 9명 |
| 마른 휴지로도 충분하다 | 33.3% | 6명 |
| 물티슈도 귀찮아서 안 쓴다 | 16.7% | 3명 |

**핵심 인사이트:** 응답자 절반이 더 쾌적한 대안이 있다면 기꺼이 사용할 의향 있음.

> ⚠️ **추가 설문 필요:** 표본을 n=100+ 으로 확대하고, "기능성 폼(세정+보습+영양)이라면 더 쓸 의향이 있는가?", "변비 여부" 항목을 포함할 것.

## 4. 경쟁사 분석

### 4-1. 글로벌 경쟁사

#### CWS Hygiene (독일 기반, 유럽 B2B 강자)

| 항목 | 내용 |
|------|------|
| 제품 형태 | 전기식 자동 분사 디스펜서 |
| 비즈니스 모델 | **구독형 B2B** — 디스펜서 무상 임대 + 소모품(폼, 티슈) 월정액 공급 |
| 유통 전략 | 자체 영업망 + 건물 관리사 파트너십 |
| 주요 고객 | 유럽 오피스, 공공기관, 의료시설 |
| 강점 | 구독 모델 검증, 강력한 B2B 레퍼런스 |
| 약점 | 전기 설치 필요, 한국 시장 미진출 (진입 여지), 폼 성분 차별화 없음 |

**시사점:** 구독형 B2B 모델은 이미 시장에서 검증됨. 우리는 **전원 불필요 + 기능성 폼**으로 진입 장벽을 낮추면서 차별화한다.

#### Tushé (미국, D2C + 홈 타겟)

| 항목 | 내용 |
|------|------|
| 제품 형태 | 센서 기반 자동 분사 (가정용) |
| 비즈니스 모델 | 하드웨어 판매 + 리필 카트리지 구독 |
| 타겟 | 가정용 소비자 (프리미엄 D2C) |
| 강점 | 브랜딩 강함, 소비자 경험 중심 |
| 약점 | 전원 필요, B2B 채널 없음, 배터리 관리 필요 |

**시사점:** D2C 브랜딩 방향성은 참고할 만하나, 우리는 공중화장실 B2B가 핵심. 하드웨어 의존도를 낮추고 **폼 포뮬러로 재구매를 유도**하는 구조가 더 강하다.

### 4-2. 국내 경쟁사 및 유사 시장

| 구분 | 현황 |
|------|------|
| 비데 (코웨이, 청호나이스 등) | 가정용 중심, 공중화장실 설치 불가 (배관·전기 필요) |
| 물티슈 | 가장 넓은 대안. 변기 막힘·쓰레기 문제로 공중화장실 비치 제한적 |
| 뿌리는 비데 폼 (개인 휴대용) | 소수 사용자. 휴대 불편, 공중화장실 비치 불가 |
| 공중화장실 폼 디스펜서 | **국내 미진출 or 극히 소수** — 블루오션 |

**국내 시장 결론:** 공중화장실 대상 기능성 폼 디스펜서는 사실상 국내 경쟁자 없음. **선점 기회.**

### 4-3. 경쟁 포지셔닝 맵

```
                  기능성 폼 성분 (高)
                        │
              FoamFit   │
           [목표 포지션] │
                        │
전원 불필요 ─────────────┼───────────── 전원 필요
                        │        CWS Hygiene
                        │             Tushé
                        │
                  기능성 폼 성분 (低)
```

> 우리의 목표: **"전원 불필요 + 기능성 폼"** 사분면 단독 선점

## 5. 전략 피벗: 폼 포뮬러 중심 차별화

### 5-1. 왜 폼 포뮬러인가

하드웨어(기계식 모듈)는 장기적으로 경쟁사가 모방 가능하다.
그러나 **자체 개발한 기능성 폼 포뮬러**는 특허 + 성분 노하우 + 브랜드 인식으로 강력한 해자를 구축한다.

```
세정(Cleansing)  +  보습(Moisturizing)  +  영양(Nourishing)
       │                  │                      │
  불쾌감 제거          피부 자극 최소화        피부 건강 개선
  (기본 니즈)          (차별화 포인트 1)       (차별화 포인트 2)
```

### 5-2. 폼 포뮬러 개발 방향

| 기능 | 목표 성분 (예시) | 효과 |
|------|-----------------|------|
| 세정 | 저자극 계면활성제 (코코베타인 등) | 잔여물 제거, 화장지 찢어짐 방지 |
| 보습 | 히알루론산, 판테놀, 알로에 추출물 | 민감한 피부 보호, 건조함 방지 |
| 영양 | 비타민 E, 식물성 오일 (호호바 등) | 피부 컨디셔닝, 사용 후 촉촉함 |
| 안전성 | 무향 / 저자극 / 피부과 테스트 완료 | 공중화장실 불특정 다수 사용 가능 |

> ⚠️ 성분 확정은 피부과학 전문가 또는 코스메틱 ODM 협력사와 공동 진행 예정

### 5-3. 폼 포뮬러를 핵심 자산으로 만드는 로드맵

```
Phase 1: OEM 폼으로 시장 진입 (검증 우선)
   → 기존 ODM 제조사 폼을 사용, 비용·시간 최소화

Phase 2: 자체 포뮬러 개발 (세정+보습+영양 3중 기능)
   → 피부과학 전문가 협력, ODM 제조사와 공동 개발
   → 사용자 데이터 기반 성분 최적화

Phase 3: 특허 출원 + 자체 브랜드 론칭
   → 핵심 성분 조합 특허 보호
   → "FoamFit Formula" 브랜드 인증 마크 도입
   → 리필 카트리지 구독에서 프리미엄 마진 확보
```

## 6. 솔루션 설계

### 6-1. 하드웨어 구조

```
[ 점보롤 디스펜서 ]  ───  기존 그대로 유지
        ↓
[ FoamFit 부착 모듈 ]
  ├─ 기계식 펌프: 화장지 인출 시 레버 연동 → 폼 미량 분사
  ├─ 폼 카트리지: 교체형 (OEM 폼 → 추후 자체 FoamFit Formula)
  ├─ 분사 노즐: 화장지 뽑히는 지점에 위치
  └─ 사용자 Lock 스위치: 원하지 않는 사용자는 직접 끌 수 있음
```

**핵심 원리:** 화장지를 당기는 물리적 힘 → 기계식 펌프 압축 → 폼 분사. **전기·배터리 일절 불필요.**

### 6-2. 주요 설계 결정

| 항목 | 결정 사항 | 근거 |
|------|-----------|------|
| 분사 물질 | **기능성 폼 (세정+보습+영양)** | 단순 세정제 대비 사용 경험 월등 + 재구매 유인 |
| 제품 형태 | 모듈형 (기존 디스펜서 부착) | B2B 도입 장벽 최소화, PoC 용이 |
| 트리거 방식 | 기계식 레버 연동 | 전원 불필요, 자연스러운 사용 흐름 |
| 전원 | 없음 (순수 기계식) | 설치·유지 비용 제로, 전기공사 불필요 |
| Lock 제어 | 사용자 직접 온/오프 | 원하지 않는 사용자 선택권 보장 |
| 폼 공급 전략 | OEM 시작 → **자체 FoamFit Formula 개발** | 빠른 출시 + 장기 IP 해자 구축 |
| 파트너십 전략 | 디스펜서 제조사 공동개발 우선 | 호환성 해결 + 기존 유통망 활용 |

### 6-3. 작동 흐름

```
① 손을 뻗어 레버를 당긴다
      ↓
② 기계식 펌프가 압축된다 (전기 없음)
      ↓
③ 노즐에서 기능성 폼이 미량 분사된다 (세정+보습+영양)
      ↓
④ 폼이 묻은 화장지로 물티슈처럼 닦는다

※ Lock 스위치 ON 시: 분사 없이 일반 화장지로 사용
```

## 7. B2B 전략

### 7-1. 타겟 고객

| 타겟 | 이유 |
|------|------|
| 고속도로 휴게소 | 유동인구 최대, 빠른 사용 데이터 확보 가능 |
| 공공기관 (정부·지자체 청사) | 공공 위생 개선 명분, 대규모 계약 가능 |
| 대형 쇼핑몰·복합시설 | 방문객 만족도 차별화 포인트 |
| 기업 오피스 빌딩 | 총무팀 의사결정 빠름, 피드백 품질 높음 |
| 프리미엄 호텔·리조트 | 기능성 폼 차별화가 고급 이미지와 부합 |

### 7-2. 설득 포인트

| 예상 반론 | 방어 논리 |
|-----------|-----------|
| "휴지 사용량 늘어 비용 증가 아닌가?" | 물티슈 변기 막힘 수리 비용 절감이 훨씬 큼 |
| "설비 교체 비용이 부담스럽다" | 기존 디스펜서 그대로, 모듈만 부착 (5분 설치) |
| "관리가 번거롭지 않나?" | 카트리지 정기 구독 하나로 관리 일원화 |
| "전기 공사가 필요한가?" | 순수 기계식, 전원 일절 불필요 |
| "사용자가 거부감 느끼지 않나?" | Lock 스위치로 개인 선택권 보장 |
| "CWS 같은 글로벌 제품과 다른가?" | 전원 불필요 + 세정·보습·영양 기능성 폼은 국내 유일 |

## 8. 비즈니스 모델 & 로드맵

### 수익 구조

| 수익원 | 방식 | 비고 |
|--------|------|------|
| 모듈 판매 | 초기 하드웨어 판매 | 원가 근접 가격으로 진입 유도 |
| 폼 카트리지 구독 | 월정액 or 사용량 기반 | **핵심 수익 — Formula 마진 포함** |
| 파트너십 수익 | 라이선스 or 공동 수익 배분 | Phase 1 주요 수익 |
| 포뮬러 라이선스 (장기) | 자체 Formula 외부 라이선싱 | Phase 3 이후 옵션 |

### 3단계 로드맵

```
Phase 1 (0~12개월): 파트너십 + 시장 진입
  ├─ 디스펜서 제조사 파트너십 체결
  ├─ OEM 폼 세정제 공급 계약 (빠른 출시)
  ├─ PoC 시범 설치 (고속도로 휴게소 우선)
  ├─ 기계식 펌프 프로토타입 완성
  └─ 사용자 반응 데이터 수집 (폼 성분 선호도 포함)

Phase 2 (12~24개월): 자체 포뮬러 개발 + 구독 정착
  ├─ FoamFit Formula 개발 (세정+보습+영양, 피부과학 협력)
  ├─ 자체 카트리지 출시 + 구독 모델 전환
  ├─ 사용량 데이터 기반 성분 최적화
  └─ 고객사 레퍼런스 확보

Phase 3 (24개월+): IP 확보 + 자체 브랜드 확장
  ├─ FoamFit Formula 특허 출원
  ├─ FoamFit 독립 브랜드 론칭 ("기능성 폼" 포지셔닝)
  ├─ 직접 B2B 영업 확장
  └─ D2C 가능성 탐색 (가정용 미니 모듈)
```

## 9. 고객 인터뷰 가이드 *(미실시 — 예정)*

> 다음 인터뷰는 아직 진행되지 않았습니다. B2B 타겟 고객사 담당자 및 실제 사용자 대상으로 진행 예정입니다.

### B2B 구매 담당자 대상 질문

1. 현재 화장실 위생 관련 가장 큰 불만/비용은 무엇인가요?
2. 물티슈 관련 변기 막힘 문제를 경험한 적 있나요? 처리 비용은?
3. 기존 디스펜서에 모듈만 부착하는 솔루션이라면 도입 의향이 있나요?
4. 카트리지 구독 방식으로 공급된다면, 월 얼마까지 수용 가능한가요?
5. "세정+보습+영양" 기능성 폼이 일반 폼과 다르게 느껴지나요?

### 실제 사용자 대상 질문

1. 공중화장실에서 화장지 사용 시 가장 불편한 점은?
2. 화장지에 폼이 자동으로 묻어 나온다면 사용할 것 같나요?
3. "세정만" vs "세정+보습+영양" 중 더 끌리는 것은?
4. 폼 사용을 원하지 않을 때 Lock 스위치를 직접 끌 수 있다면 불편하지 않나요?
5. 이 경험이 물티슈를 대체할 수 있을 것 같나요?
6. (변비 여부 확인 후) 변비가 있으신가요? 있다면 닦는 횟수나 불편함이 더 크게 느껴지나요?

## 10. 파일럿 설계 *(미실시 — 예정)*

> 아래는 첫 PoC(파일럿) 설치를 위한 설계안입니다. 아직 실행되지 않았습니다.

### 파일럿 목표

- 기계식 모듈의 실제 내구성 및 오작동률 측정
- 사용자 폼 선호도 및 거부율 측정 (Lock 사용률)
- 카트리지 교체 주기 및 소모량 파악

### 파일럿 세부 계획

| 항목 | 내용 |
|------|------|
| 장소 | 고속도로 휴게소 화장실 (1~2개 화장실) |
| 기간 | 4주 |
| 설치 대수 | 5~10대 (남녀 화장실 포함) |
| 측정 지표 | 폼 소모량, Lock 스위치 사용률, 불만 접수 건수, 카트리지 교체 횟수 |
| 피드백 수집 | QR코드 설문 (화장실 내 부착), B2B 담당자 인터뷰 |
| 성공 기준 | Lock 사용률 30% 미만, 사용자 만족도 70% 이상 |
